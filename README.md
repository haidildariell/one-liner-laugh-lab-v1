Entry for the [One-Liner Laugh Lab](https://make.fun/c/u-suroso-69-one-liner-laugh-lab-6ccf3aae) competition on make.fun.

## What it does

`main.ts` writes a single short funny line to `/output/entry.txt`: the excuse a robot vacuum gives after eating a sock. The line is an original deadpan confession — the vacuum admits it ate the sock, then blames the sock itself for being on the floor, smelling of feet, and having given up on life.

## Run

```sh
node main.ts
```

It writes `/output/entry.txt` (93 characters, one line, UTF-8).
